# 测试夹具（可复用）

## `handcalc.json`

手算固定夹具，被三类消费者复用：

1. `tests/http_api.rs::http_handcalc_fixture` — 在 Axum oneshot 上逐步执行
   注册/批/拒绝/重建，并对每个 `queries[*]` 断言精确 `sum`；
2. 与 `tests/service.rs::handcalc_fixture_end_to_end` 中的手算字面量一一对应
   （同一组数字，服务层再与独立全扫描 oracle 比对）；
3. `scripts/smoke_http.py` 对真实进程做 HTTP 冒烟（数字保持一致）。

字段含义：

- `register`：v1 的两轴坐标（含负数、无序输入由实现排序去重）；
- `batches`：必然成功的批，按顺序产生 v2、v3；
- `rejected_batches`：必须失败的批，`error_code` 是期望的稳定错误类别，
  失败不得产生新版本；
- `rebuild`：产生 v4 的新坐标表；
- `queries`：`(at_version, 矩形四边, sum[, empty])`，**期望值手工计算**，
  覆盖：重复坐标累加、负权、坐标间隙空结果、反向空矩形、边界包含、
  `i64::MIN/MAX` 极端坐标、重建后携值/丢点、以及重建后旧版本仍可查询。

手算依据（v2/v3/v4 全平面）：

```
v1 注册                 : 全 0
v2 +(-5,-3,3) +(0,2,-5) +(7,100,10) : 3-5+10 = 8
v3 +(-5,-3,-3)          : 0-5+10   = 5   （(-5,-3) 回到 0）
v4 rebuild {0,7,42}x{2,100}: (-5,-3) 被移除，(0,2)=-5 与 (7,100)=10 携入 : 5
```

## 随机性夹具

没有单独的随机数据文件：随机测试使用**固定种子 LCG**
（`tests/common/mod.rs::rng::Lcg::seeded(...)`），种子写死在用例里
（`0x5151_2026`、`20260928` 等），任何机器上生成的输入序列一致，失败时
CaseLog 会转储迭代号、矩形与全部点权，可据此重建输入。

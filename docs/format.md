# 存储格式 v1 与索引内核约定

本文档固定所有影响磁盘兼容与成员判定结果的细节。**不抬升 `FORMAT_VERSION` 不得修改。**

## 1. 哈希内核（小端，全 64 位运算）

使用 XXH64（r44 质数），三个固定种子：

| 用途 | 种子（hex） |
|---|---|
| 主桶 `h1` | `0x434B465F41310001` |
| 指纹 `h2` | `0x434B4F4F4B463202` |
| 指纹→桶位移 | `0x434B465F46504944` |

对键字节 `key`：

```
h1 = XXH64(key, SEED_H1)
h2 = XXH64(key, SEED_H2)
fp = (h2 mod (2^f - 1)) + 1          # 指纹域 1..2^f-1，0 保留为空槽
i1 = h1 mod b                        # b = 2^buckets_exp 个桶
i2 = i1 XOR (XXH64(LE32(fp), SEED_FP_INDEX) mod b)
```

- 指纹恒非零、恒 `< 2^f`；
- `alt(i, fp) = i XOR (XXH64(LE32(fp), SEED_FP_INDEX) mod b)` 是对合：
  `alt(alt(i1,fp),fp)=i1`，因此迁移与删除只需 `(桶, fp)` 即可定位另一家；
- 桶数取 2 的幂，XOR 后再与 `b-1` 掩码保证下标在界内。

## 2. 插入与迁移

1. `i1` 有空槽直接放；否则 `i2` 有空槽直接放。
2. 否则从 `i1/i2` 中等概率选一个起迁；每一步用确定性 RNG（SplitMix64）选择
   被踢槽位，把当前指纹换入，被换出指纹去它的另一个候选桶继续。
3. 最多 `max_kicks` 步；任一步在目标桶找到空槽即成功，并返回
   **逐次换槽轨迹**（`swaps[].evicted_fp` + 最终 `placed`）。
4. 超限：用插入前完整快照恢复槽位与占用计数，返回 `FILTER_FULL(max_kicks)`。

固定 `rng_seed` + 固定输入序列 ⇒ 迁移路径完全可复现（验证场景 S02 据此逐槽比对）。

## 3. 删除为什么需要凭证

朴素 Cuckoo Filter 的删除是"在候选桶里找到相同指纹就删一个"。但成员查询本身有假
阳性：两个不同键可能共享同一指纹且落在彼此的候选桶里，此时仅凭 `contains=true`
删除，可能移走**别的键**的副本，极端情况下造成存活键假阴性。

本实现把每次插入的副本绑定到一个槽：

- 插入成功后，服务端把随机 128 位 `jti` 写入该副本最终占用的槽的"归属表"，
  迁移过程中归属随换槽轨迹一起移动（与指纹同序 swap）；
- 凭证 `token = base64url(jti) + "." + base64url(HMAC-SHA256(master_key, jti||0x00||key))`；
- 删除：先校验 HMAC（常量时间，且把凭证与**确切键字节**绑定），再在归属表里找该
  `jti` 当前唯一拥有的槽，只清零这一个槽，校验槽内指纹与账本一致，然后删除账本项；
- 账本项删除后同凭证再用即 `CREDENTIAL_EXHAUSTED`（含跨进程重启，因为账本随快照持久化）。

因此：攻击者/误调用方即使知道一个查询为真的键，没有对应凭证也无法删除；
凭证无法跨键使用、无法用另一把主密钥伪造、无法重放。

> 边界：若同一键重复插入，各副本是独立凭证；删除按凭证逐个进行，计数精确。

## 4. 快照二进制布局（全小端）

```
偏移   长度  字段
0      8    magic = b"CKCFILTR"
8      4    format_version = 1
12     4    buckets_exp
16     4    bucket_size            (2 或 4)
20     4    fingerprint_bits       (4..=16)
24     4    max_kicks             (>0)
28     8    occupied              (非空槽计数)
36     4    slots_len             = 2^buckets_exp * bucket_size
40     4    owners_off            = 48 + 2*slots_len
44     4    reserved              = 0
48     2L   slots                 每槽 u16（f<=16），0=空槽
48+2L  16L  owners                每槽 16 字节 jti；空槽必须全 0
末尾   8    checksum = XXH64(seed=0x434B465F43484B31, 此前全部字节)
```

装载时强制：magic/版本；参数范围；`slots_len` 与参数一致；`owners_off` 正确；
文件长度；校验和；每个指纹 `<= 2^f-1`；非空槽必有非零 jti、空槽必为零 jti；
jti 全局唯一；`occupied` 等于非空槽数。任一不符即拒绝打开。

写入：同目录临时文件 → `write_all` → `fsync(file)` → `rename` 原子替换 →
`fsync(dir)`。因此崩溃只可能保留旧快照或新快照之一，不会产生混合/截断文件
（截断文件由长度与校验和检查兜住）。

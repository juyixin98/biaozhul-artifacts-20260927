# 未执行 / 无法执行的检查

本文件**单独列出**本后端没有做、或在本地夹具范围内无法完成的检查。
这些项**不得**在任何报告或文档中表述为“已通过”。它们是范围边界，不是缺陷声明。

## A. 协议层明确不实现（超出“受限 PES / PAT / PMT”范围）

1. **除 PAT/PMT 外的所有 PSI/SI 表**：NIT、CAT、TSDT、SDT、EIT、TDT/TOT、
   BAT、RST、ST、SIT、DIT 等。遇到时只做 CRC 校验并发 `unsupported_table`，
   不解析语义。
2. **媒体 ES 解码**：H.264/H.265/AV1/AAC/MP3 等编码内容不解码，不校验访问单元、
   帧类型、slice、编码器时序或码流语义。PES 负载是不透明字节。
3. **PES 可选字段的完整语义**：ESCR、ES_rate、DSM trick mode、附加版权信息、
   PES 扩展字段、CRC 等不解析（仅定位 PTS/DTS 与负载起点）。
4. **PTS/DTS 合法性门限**：不强制校验 90 kHz 时间戳单调性、PTS−DTS 间隔、
   音视频唇音同步或时间戳回绕窗口的业务阈值（只解析数值；PCR 回退单独检测）。
5. **加扰流内容**：`transport_scrambling_control != 0` 的净荷不解密、不解释；
   不实现任何 CSA/AES 解扰。
6. **私有数据 / 私有流描述子**：PMT 描述子只按长度跳过，不解释私有语义。
7. **204 字节包（带 Reed–Solomon 校验）与 192 字节时间戳格式**：只支持 188 字节。
8. **多节目参考时钟一致性、PCR 精度（PTS/PCR 偏差）、漂移锁相环（PLL）**：
   只给间隔/抖动/速率的描述性统计，不做合规门限判定。

## B. 无法在本地合成环境完成的检查

1. **真实网络/硬件接收路径**：DVB-S2/T、ATSC、ISDB、ASI、SMPTE-ST 310 等
   调谐器/RF 损伤、误码率、信号电平不存在；TEI 只能由夹具人为置位。
2. **生产规模压力验证**：默认上限 `max_input_bytes=64 MiB`、
   `max_section_bytes=4096`、`max_pes_payload_bytes=256 KiB`。超长时连播、
   超大表（如巨型 EIT）、数万 PID 的长期稳定性**未**在本工程内测量。
3. **真实采集的丢包分布与突发模式**：缺包由夹具按确定性位置构造
   （如删除索引 1、2 的满包），不代表真实网络的突发/乱序分布；不做乱序重排恢复。
4. **与外部参考实现的字节级对拍**：未在本环境安装 `ffprobe`/`TSDuck`/`ffmpeg`，
   因此“与外部工具输出一致”的检查**未执行**。夹具旁车
   （`tests/fixtures/data/*.expect.json`）可用于在装好这些工具的环境里手工对拍。
5. **并发安全的形式化验证**：作业存储用单连接 + 锁，配套了多 worker 的功能测试，
   但没有做高并发压测或竞态形式化证明。
6. **时间相关的确定性**：作业时间戳使用本机时钟；测试只断言状态迁移，不断言
   绝对时间值。

## C. 已实现但需要注意的判定局限

1. **`PES_packet_length == 0` 且结束于短净荷包**：最后一个 TS 包内适配填充与
   ES 字节在无声明长度时不可区分，`payload_bytes` 为上界（见 boundary 文档 §5）。
2. **同步确认依赖至少 3 个同步字**：不足 3 个包的极短流无法确认锁定，
   会判 `indeterminate`；测试夹具通过补一个空包满足窗口，这是有意为之。
3. **表内容“同 version 但内容变了”**：实现会把它当作一次更新（事件为
   version_switch）。严格协议下 version 不变则内容应不变；本工程选择
   “可观察到变化就原子替换并留痕”，不额外发协议一致性告警。
4. **重复包判定**依赖解析后净荷逐字节相等；若重复发生在被 TEI 标记的包上，
   其净荷本就不进入比较，不能据此判重。

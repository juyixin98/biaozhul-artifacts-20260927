# 设计契约与推导

## 1. 有理比表示

输入、输出采样率均为正整数。约去最大公约数：

```
g = gcd(f_in, f_out);  L = f_out/g,  M = f_in/g,  gcd(L,M)=1
f_out / f_in = L / M
```

在概念高采样率网格 `F_h = L·f_in = M·f_out` 上，输入样本位于 `k·L`，
输出在抽取前位于 `n·M`。只接受精确整数比是为了让相位序列周期严格为 L，
不存在浮点相位漂移。

## 2. 多相结构与输出 n 的定义

原型低通 `h` 长度 `N = K·L`（K 为每相抽头数，偶数）。多相列定义为

```
P[p, a] = h[a·L + p],     p = 0..L-1,  a = 0..K-1
```

输入流在开头补 K−1 个零（引导填充）后记为全局样本
`x_in[q]`（真实 x[0] 位于全局下标 K−1）。第 n 个输出为

```
p(n) = (n·M) mod  L
q(n) = (n·M) div  L  = floor(nM/L)
y[n] = Σ_{a=0..K-1} P[p(n), a] · x_in[q(n) − a]
```

等价于经典的“零值插入 L → 原型滤波 → 按 M 抽取”的 `upfirdn`
（测试与 `scipy.signal.upfirdn` 逐样本一致，最大绝对差 ≲ 2.2e-15）。

**时间对齐。** 原型关于 `(N−1)/2`（高采样率样本）对称，群延迟
`(N−1)/2 = (K−1)·L/2 + (L−1)/2`。考虑 L 插值与 M 抽取后，输出 n 对应
输入域时间

```
t(n) = (n·M − (K−1)/2) / (L·f_in)
```

即内核对输入的群延迟为 **(K−1)/2 个输入样本**。需要零相位对齐时，
在输出时间轴上去掉该延迟（`/validate` 与结果头均给出）。

## 3. 抗混叠/抗镜像滤波器

两种操作共用同一支原型：升采样要抑制零值插入镜像，降采样要阻止
`f_out/2` 以上能量折叠。共同通带是两者 Nyquist 的较小者。

以 `F_h` 为基准（奈奎斯特=0.5 周/样本）：

```
阻带边 ω_s = 0.5 · min(1/L, 1/M)          # = min(f_in,f_out)/(2 F_h)
通带边 ω_p = ρ · ω_s,        ρ 默认 0.9
过渡宽 Δω  = ω_s − ω_p
截止 ω_c  = (ω_p + ω_s)/2                 # 窗化 sinc 的 -6dB 附近
```

设计步骤：

1. Kaiser 形状参数（A 为目标阻带衰减 dB，默认 80）：
   `A>50 → β=0.1102(A−8.7)`；`21≤A≤50 → β=0.5842(A−21)^0.4+0.07886(A−21)`。
2. 阶数估计 `N_est = (A−7.95)/(14.36·Δω)`，取 `K = ceil(N_est/L)`，
   钳到最小每相抽头（默认 8）并向上取偶；`N=K·L` 超过
   `max_filter_taps` 即报资源耗尽。
3. 中心在半样本网格的偶长对称窗与截断 sinc：
   `h0[k] = sinc(2·ω_c·(k−(N−1)/2)) · w_Kaiser(k)`
   （NumPy 的 `sinc(u)=sin(πu)/(πu)`，理想离散低通为
   `2ω_c·sinc(2ω_c·k)`）。
4. **单一全局归一化** `h = h0 · L / Σh0`，使 `Σh = L`：
   零值插入支路 DC 增益为 1，整个重采样器 DC 增益恰为 1，且不破坏
   Kaiser 过渡带形状。（逐列各自归一化为 1 会在列间重新分配增益、
   使阻带边形状畸变，故明确不采用；实测各列 DC 增益纹波 ≤ 2e-4，
   属截断固有量。）

实测（1<<18 点 FFT，越过阻带边一个过渡宽起测）：48k→16k、16k→48k、
48k↔44.1k、11.025k→48k、22.05k→8k 最差阻带均约 **−89 ~ −91 dB**。

## 4. 流式状态与“切块不变性”

内核只持有：

* `hist`：最近 K−1 个输入样本（最初为引导零）；
* `J`：已接收输入数；`next_n`：下一个待输出的全局 n；
* `flushed`：终态标志。

每次 `push` 把 `hist` 与新块拼成 `seq`，发射所有窗口已完全落在
`seq` 内的输出 n：

```
q(n) ≤ last_global   ⇔   n ≤ ceil(L·(last_global+1)/M) − 1
```

边界处不做任何重采样决策，块边界不携带信息，因此任意切分产生的
输出序列与计数逐位相同（测试对 12 种切分做 `array_equal`）。

`flush` 追加 K−1 个尾随零，发射剩余窗口；二次 flush / flush 后 push
均为状态冲突。

## 5. 输出样本计数

最后一个可能非零的输出满足 `q(n) ≤ J+K−2`（真实输入 0..J−1 加
K−1 尾零），故

```
J = 0 → 0 个输出
J ≥ 1 → n_out = ceil( L·(J+K−1) / M )
```

flush 完成后内核断言实际计数与此相等，否则报计算失败。

升采样时朴素的“全卷积后抽取”长度 `ceil((J·L+N−1)/M)` 可能多出至多
2 个输出，它们对应的 K 抽头窗口只碰到零值插入位置（恒为零）；
内核与 SciPy `upfirdn` 都不发射这些零样本，测试中的 FFT 参考
按上式显式裁掉。

## 6. 非有限值与溢出

* **输入侧**：整数/浮点 PCM 解码后立即做有限性检查，NaN/Inf →
  输入错误（400），不进入内核。
* **内核侧**：向量化点积后再做一次有限性检查作为自卫，命中即
  计算失败（500，带首个坏输出下标）。
* **输出侧**：浮点格式做范围转换检查（f64→f32 可能溢出）；
  整数格式四舍五入（NumPy 默认银行家舍入）后：
  * `clip`：饱和到码制端点并统计 `clipped_samples`；
  * `reject`：输出溢出（422），作业失败。
  u8 中心码 128；对称整数码的负满幅 −1.0，正满幅 `(2^(b−1)−1)/2^(b−1)`。

## 7. 媒体边界

* raw：按格式宽度切分，长度未对齐即拒绝。
* WAV：自实现最小 RIFF 解析，仅接受 PCM(format=1)/IEEE float(format=3)
  单声道；多声道、压缩标签、缺 fmt/data、chunk 越界、数据未对齐一律
  输入错误。输出 WAV 写出正确字节率并在 float 时附 `fact` 块。

## 8. 持久化与可观测性

SQLite（WAL）三张表：`jobs`（计划参数、状态、计数、错误三元组）、
`chunks`（每块原始输入，可审计重放）、`outputs`（每段 f64le BLOB 与
该段饱和计数）。每个请求/测试有 run 目录，`events.jsonl` 记录创建、
每块处理前后的内核快照、每类失败与理由；`summary.json` 汇总断言。

## 9. 复核方式的独立性

* `scipy.signal.upfirdn`：相同原型、**独立实现**（SciPy 的 C 代码路径），
  用于逐样本精确对照（容差 4e-14）。
* `tests/reference.py::fft_poly_ref`：零值插入 + FFT 全卷积 + 抽取，
  **独立构造与实现**（NumPy 手写，尾样本计数独立推导）。
* 频谱断言（混叠/镜像/通带增益）用相干 DFT 在整周期信号上测量，
  不依赖被测滤波器或其频率响应。

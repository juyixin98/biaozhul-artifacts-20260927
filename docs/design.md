# 设计说明：有理比率多相 FIR 重采样

本文档给出实现所依据的精确约定，便于逐行核对
`src/resamp/dsp/`。所有公式与代码中的变量同名。

## 1. 比率约简

输入、输出采样率 `fin, fout`（正整数）：

```
g  = gcd(fin, fout)
L  = fout / g          # 上采样（零填充）因子
M  = fin / g           # 下采样（抽取）因子
fh = L·fin = M·fout    # 中间“高采样率”
```

`L, M` 互质。要求采样率为正整数、不超过 `max_rate`，且
`max(L,M) ≤ max_ratio_factor`，否则按错误契约报 `invalid_input` 或
`resource_exhausted`。

## 2. 原型低通滤波器

零填充会引入镜像，抽取会引入混叠；一个放在高采样率 `fh` 上的低通同时
解决两者。截止取新、旧 Nyquist 中较小者：

```
fc = min(fin, fout) / 2
```

过渡带以 fc 为中心（`half = transition_half_width`，默认 0.1）：

```
fpass = (1 - half)·fc
fstop = (1 + half)·fc
Δf    = fstop - fpass = 2·half·fc
```

Kaiser 窗设计（目标阻带衰减 A dB，默认 80）：

```
β = 0.1102·(A − 8.7)                                   A > 50
  = 0.5842·(A − 21)^0.78 + 0.07886·(A − 21)            21 ≤ A ≤ 50
  = 0                                                   A < 21

N = ceil((A − 7.95) / (2.285·2π·(Δf / fh))) + 1        （向上取奇）
H = (N − 1) / 2
```

理想加窗 sinc（`wc = 2π·fc/fh`）：

```
h0[n] = sin(wc·n)/(π·n),   n = −H..H    （n=0 取 wc/π）
w[n]  = I0(β·sqrt(1 − (n/H)^2)) / I0(β)
h[n]  = h0[n]·w[n] · L / Σ(h0·w)
```

最后一步把直流增益归一化到 **L**：零填充流上的低通在直流处增益为 L，
配合多相臂后，输入→输出的整体直流增益恰好为 1。`I0` 用幂级数自包含实现
（`fir.bessel_i0`），不依赖 scipy。

滤波器为 I 类（奇数长、关于中心抽头对称），群延迟为整数 `H` 个高采样率样本。
若 `H < L−1`（极端比例 + 极宽过渡带时最短臂可能没有内部抽头），直接报
`resource_exhausted`，而不是静默退化。

## 3. 多相分解

零填充与卷积定义：

```
xz[k] = x[k/L]   若 k % L == 0，否则 0
yz[k] = Σ_q xz[k−q]·h[q]
y[n]  = yz[n·M]
```

令 `k = n·M`、`p = k mod L`。只有 `q = p + j·L` 的项命中非零的 xz：

```
y[n] = Σ_j x[ floor(k/L) − j ] · h[ p + j·L ],   −H ≤ p + j·L ≤ H
```

相位 `p` 与臂的抽头范围只取决于 `(n·M mod L)`：

```
j0(p) = −⌊(H + p)/L⌋
j1(p) =  ⌊(H − p)/L⌋
```

实现按相位分组取臂系数 `coeffs[H + p + j·L]`，对落入区间的输入索引做一维
`np.dot`。

## 4. 流式索引、固定首尾填充与发射条件

输入按全局索引计，`x[0]` 是第一个真实样本；头部固定补

```
P = H // L
```

个零（即 `x[−P..−1] = 0`）。输出 `n` 的中心输入索引是 `floor(nM/L)`，
其臂向后最远读到

```
b(n) = floor(nM/L) + ⌊(H + (nM mod L))/L⌋
```

**流式发射条件（未 flush）**：仅当所有抽头都落在“已收到的真实样本或固定
前导零”内，即

```
b(n) ≤ N_in − 1
```

才输出 y[n]；否则扣留，等待后续输入。因为有前导零，最早的输出即便真实样本
很少也能产生。

**flush**：尾部固定补 `Z = 2H//L + 2` 个零（该量对任何 L、H 都不短于最长
向后跨度），然后输出到全卷积边界。

### 输出时间对齐

因为对称滤波器与固定前导零，流中部位于输入 `p` 的脉冲，其输出峰值出现在

```
n_peak = floor(L·p / M)
```

（滤波器本身 H 个高采样率样本的群延迟被前导零补偿；群延迟数值仍在
`design_summary()` 中显式报告，供需要按物理时间对齐的下游使用。）

## 5. 确定性输出计数

`N_in ≥ 1` 时，flush 后输出样本数严格为

```
N_out = floor((L·(N_in − 1) + H) / M) + 1
```

推导：flush 允许的最大输出满足

```
floor(n·M / L) + floor((H + (n·M mod L)) / L) ≤ N_in − 1
                ⇔  floor((n·M + H) / L) ≤ N_in − 1
                ⇔  n·M + H < L·N_in
```

最大的整数 n 为 `ceil((L·N_in − H)/M) − 1`，化简即上式。`N_in = 0` 时
没有“第一个真实样本”，输出恒为 0。代码与独立测试都直接断言该闭式，而不是
仅比较累加长度。

## 6. 数值与确定性约定

* 输入只接受 1-D `float64`、有限值；非有限值报 `invalid_input` 并给出首个
  越界下标。
* 累加为 `float64`；输出可请求 `float32`（先做范围检查再转换，越界报
  `computation`）。
* **分块逐位确定性**：批量矩阵-向量乘（GEMV）在 NumPy 中会随行数改变归约
  顺序（实测出现 1 ULP 差异）。因此每个输出固定使用一维 `np.dot`，其归约
  核不随本次调用的输出条数变化，从而任意切块的拼接结果逐位相同
  （`np.array_equal`）。

## 7. 独立高精度参考

`dsp/reference.py` 走另一条算术路径：

1. 显式构造 `xz`（长度 `L·N`）；
2. 一次长度为 `next_fast_len(LN + 2H)`（2/3/5-smooth）的零填充循环 FFT
   全卷积；
3. 按 `y[n] = conv_full[n·M + H]` 取点，取到第 5 节同样的上界。

它与核心共享 `fir.design_prototype`（设计表等价物），但**不共享**多相
索引、流式状态或点积路径，因此可作为独立复核。内部样本实测误差约 1e-15。

## 8. 媒体/服务/持久化边界

* `media.py`：无压缩 PCM WAV（format tag 1）、单声道、16/24/32-bit，
  统一以 `c / 2^(b−1)` 对称缩放为 `[−1,1]` 浮点；编码侧 `+1.0` 钳到
  `2^(b−1)−1`、`−1.0` 精确为 `−2^(b−1)`。
* `storage.py`：SQLite 表 `jobs / chunks` 保存状态与每块 `n_in/n_out`，
  输出以追加的小端 float64 写到 `data/jobs/<id>.out.f64`。
* `service.py`：作业状态机、单块/总量资源限额、base64/json 解码；错误全部
  为 `errors.ResampError` 子类，HTTP 层只按 `http_status/category` 映射。
